Common Questions

Are my files really not uploaded?

Yes. Open the browser's DevTools → Network tab. You will see zero requests to any server while processing. Everything happens in JavaScript using pdf-lib, jsPDF, and pdf.js libraries loaded from CDN.

Why is this free?

Because there is no server to pay for. The tools run using your computer's resources, not ours. We offer a PRO version for heavy users who need unlimited pages and batch processing.

Can I use this for work documents?

Yes. This is actually the main reason we built these tools. You can process contracts, tax forms, and client documents without sending them to a third-party server. Many employers and clients specifically require this.

Does it work on mobile?

Yes. All tools are responsive. Tested on iOS Safari and Android Chrome.
