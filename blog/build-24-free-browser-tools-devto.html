I Built 24 Free Browser Tools That Run 100% Client-Side — No Upload, No Tracking

Published: June 2026 | Cross-post from dev.to

Six weeks ago, I started building browser-based tools as a side project. Today, I have 24 tools — and they've collectively handled zero server requests. Because there is no server.

Every tool is a single HTML file with vanilla JavaScript. Hosted on GitHub Pages. No frameworks, no build step, no backend, no database. Just a browser and some JS libraries loaded via CDN.

The Stack

The tech choices are intentionally boring:

  • Hosting: GitHub Pages (free, global CDN via Cloudflare)
  • Frontend: Vanilla HTML/CSS/JS — no React, no Vue, no build tools
  • PDF: pdf-lib, jsPDF, pdf.js (all loaded via CDN)
  • QR: qrcodejs
  • Images: Canvas API (built into the browser)
  • Crypto: Web Crypto API (crypto.getRandomValues)
  • State: localStorage (with try-catch for private browsing)

That's it. The entire "stack" is HTML files and CDN links. No backend, no CI/CD, no containers, no orchestrators.

Why Client-Side?

Most "free online tools" work like this: you upload a file to their server, they process it, you download the result. This means:

  • Your data goes to someone else's server
  • They can (and often do) track you
  • The service stops working if they shut down
  • Upload speed limits the experience

Client-side tools solve all of this. Every tool runs in the user's browser using the File API, Canvas API, and Web APIs. Nothing is uploaded. No data is sent over the network. It works offline after the first page load.

The 24 Tools (with what I learned building each)

PDF Tools

7 tools in one page: merge PDFs, split pages, images-to-PDF, PDF-to-images, extract embedded images, image-to-base64, text-to-image. The PDF merge was the hardest — merging PDFs in the browser without losing formatting requires pdf-lib, and large files (100+ pages) need careful memory management. Free limit: 125 pages.

Image Compressor

Uses the Canvas API to re-encode images at adjustable quality. Supports JPG, PNG, and WebP. The trick: draw the image to a canvas at a reduced quality setting, then export. No server-side image processing library needed. Free limit: 5MB files.

Image Resizer & Cropper

Canvas API again. Resize maintains aspect ratio by default (toggle to override). Cropper uses a draggable selection overlay. The hardest part was making the crop selection handle touch events properly.

Background Remover

This one is special: it uses the @imgly/background-removal library, which runs a neural network (ONNX runtime) entirely in the browser via WebAssembly. No API key, no server, no upload. Just a 40MB model that downloads once and caches. It's slow (~5 seconds per image) but it works completely offline.

Password Generator

Uses crypto.getRandomValues for cryptographically secure randomness. Options for character sets, length, and excluding ambiguous characters (like 1/l/I). Strength meter shows real-time entropy estimation.

QR Code Generator

Wraps qrcodejs. Supports URLs, WiFi credentials, email, SMS, phone, and vCard. The vCard format was surprisingly finicky — different phones handle field ordering differently.

JSON-CSV Converter

Parses JSON with bigint support (for large numbers) and handles nested objects by flattening keys. CSV mode auto-detects delimiters. The bidirectional conversion (JSON→CSV and CSV→JSON) was tricky because CSV has no schema, so type inference is needed.

Base64 Encoder

Encodes text and files to Base64. The file encoding uses FileReader.readAsDataURL. Also includes a string/hex/binary converter for developers debugging encoding issues.

Color Picker

Eye dropper, color wheel, and conversion between HEX, RGB, HSL, and named colors. Uses the EyeDropper API where available. The HSL↔RGB conversion math took a few tries to get right.

HTML Formatter & CSS Minifier

HTML formatter indents tags properly (handling self-closing tags, nested templates). CSS minifier strips whitespace and comments. Both use regex-based parsing which works for 95% of cases but will choke on unusual syntax.

URL Encoder

Encodes/decodes URL components and full URLs. Also handles Base64 encoded data URLs.

Timestamp Converter

Converts between Unix timestamps (seconds and milliseconds), ISO 8601, and human-readable dates. Shows relative time ("2 hours ago") and timezone-aware conversions.

Number Base Converter

Converts between binary, octal, decimal, and hexadecimal. Handles fractions and shows step-by-step conversion for educational purposes.

Random Generator

Five tabbed tools: number generator, coin flip, dice roller, list picker, and shuffle. Uses crypto.getRandomValues for fairness.

Text Diff Checker

Line-by-line and character-by-character diff with highlighted insertions/deletions. Uses a simple LCS (longest common subsequence) algorithm.

Word Counter

Counts words, characters (with/without spaces), sentences, and paragraphs. Also estimates reading time.

Case Converter

Converts text to uppercase, lowercase, title case, sentence case, and camelCase/snake_case/kebab-case for developers.

Markdown Editor

Split-pane editor with live preview. Uses the marked library for rendering. Supports GitHub-flavored markdown including tables and code blocks with syntax highlighting.

UUID Generator

Generates UUID v4 (random) and v7 (time-ordered). Bulk generation up to 1000 at once. Uses crypto.getRandomValues. v7 was interesting — it embeds timestamps for database-index-friendly ordering.

WhatsApp Chat Formatter

Parses exported WhatsApp chat logs and converts to Markdown, HTML, or CSV. Handles the various date formats, media placeholders, and emoji.

Subtitle Converter

Converts between SRT, VTT, and ASS subtitle formats. Each format has different timing precision requirements (SRT uses milliseconds, VTT uses hours:minutes:seconds.milliseconds). Text extraction mode strips all timing data.

Kindle Highlights Exporter

Parses Kindle's My Clippings.txt format (which is notoriously irregular) and exports to Markdown or CSV. Groups by book and sorts by location.

Monetization: The PRO Bundle

All 24 tools are free to use. The free versions have reasonable limits (e.g., PDF: 125 pages, images: 5MB, password: unlimited).

The PRO Bundle ($19.99) removes all limits with a single license key across all tools. One-time payment, lifetime access, 3 devices. License verification uses Gumroad's license API.

I wanted a model where the free version is genuinely useful (most casual users never hit the limits), but power users have a simple, fair upgrade path.

What I'd Do Differently

  • Start with a component library. I rebuilt the same toast notification, modal, and PRO badge across 24 files. A shared component set would have saved days.
  • Use a CDN strategy from day one. Some tools load heavy libraries (pdf-lib is 500KB+). Proper caching headers and deferred loading make a big difference.
  • SEO from the start. I added blog posts, sitemaps, and cross-links retroactively. Doing this upfront would have helped discovery earlier.

The Business Numbers

24 tools built over 6 weeks. Zero server costs (GitHub Pages is free). Gumroad handles payments (9% + $0.30 per transaction). The only cost is domain setup and some CDN bandwidth, which is negligible.

Revenue so far: $0. Building was the easy part. Distribution is the hard part.
