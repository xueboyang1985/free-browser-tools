Why "No Upload" Matters

Every tool in this suite runs entirely in your browser as static HTML + JavaScript hosted on GitHub Pages:

  • No files uploaded to any server
  • No data sent over the network
  • No cookies or trackers — literally no backend to track you
  • Works offline after initial page load
This is especially important for PDFs with sensitive content (financial documents, contracts), passwords (your generated passwords stay in your browser), and chat exports (private conversations never leave your machine).

The Tech Stack

  • Hosting: GitHub Pages (global CDN via Cloudflare)
  • Frontend: Vanilla HTML/CSS/JavaScript — no frameworks, no build steps, no bundlers
  • PDF processing: pdf-lib, jsPDF, pdf.js
  • QR generation: qrcodejs
  • Cryptography: Web Crypto API (crypto.getRandomValues)

Everything is intentionally simple. No React, no Webpack, no backend. Just HTML files you can open directly in your browser.
